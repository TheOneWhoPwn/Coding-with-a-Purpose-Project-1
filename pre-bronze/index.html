Basics of Programming

Input and Output

Input and Output is literally the first step in programming. Let's look at how it is done in C++. 

#include <bits/stdc++.h>
using namespace std;
        
int main() {
    int n, m;
    cin >> n >> m;
    cout << n+m;
}

Let's explain line by line. The first line is a header to automatically include every standard C++ library at once. It is specific to GNU GCC compiler, so make sure to download it.

The second line does a clean up for your code. So you will actually type less.

Then you declare n and m with int n, m;, and use cin >> n >> m; to intake it. Then use cout << n+m; to output the sum. And that's it.

Loops and If Statements

We will assume you know what for and while loops are. We will only look at the syntax here. 

for (int i = 0; i<n; i++) {
    
}

This is a for loop in C++. In this case it iterates from 0 to n-1. 

while (statement) {
    
}

This is a while loop in C++. As long as statement is true, the loop continues. 

if (statement1) {
    return 1;
} else if (statment2) {
    return 2;
} else {
    return 3;
}

This is a series of if statements. If statement1 is true, 1 is returned. If if statement 1 is false and statement2 is true; 2 is returned. If none of them is true, 3 is returned.

Data Strucutre

For Bronze, you will most likely only need to know how to use a vector in C++. For now, you can look at it as a list. We will look at other data structures later on and talk about the difference. 

vector<int> v1;
vector<int> v2 = {10, 20, 30};
vector<int> v3(5, 100);

These are three ways to initiate a vector. The first one is just an empty vector. The second one is initiated with some specific values. The third one is initiated with 5 100s in the vector. 

v1.push_back(1);

Simply append a value to the end of a vector. 

v1[index]

Simply access the value at the index in a vector.

Solution

Finished? or just completely stuck? Anyways, let's see how to solve the problem.

Initially, we observed that we are given a number and a list of numbers. And our goal is to find that missing number.

So we can put all the list of numbers into a vector, and then individually check if that number actually exists.

Sure that works, BUT, remember there is a time limit in competitive programming. If our code ran for too long, we will get TLE(Time Limit Exceeded).

With this solution, we need to iterate through the vector for every number. This is a O(N^2) solution. Since n can be as big as 200000 in this case, we will need to use around 4 * 10 ^ 10 steps. As a rule of thumb, any steps greater than 10^8 will get TLE.

But we can get a little clever here. We can use a boolean vector to keep track of every number we have seen. Here is what I came up with. 

#include <bits/stdc++.h>
using namespace std;
 
int main() {
	int N;
	cin >> N;
	vector<bool> data(N, true);
    for (int i = 0; i < N; i++) {
        int temp;
		cin >> temp;
		data[temp - 1] = false;
    }
 
	for (int i = 0; i < N; i++) {
		if (data[i]) {
			cout << i + 1 << endl;
			break;
		}
    }
}

This is a O(N) solution, which is much better. Here is a visualization of this code.
