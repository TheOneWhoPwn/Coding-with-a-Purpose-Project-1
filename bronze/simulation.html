Simulation

Simulation problems are arguably the easiest problem types you will encounter in Bronze.

All you really need to do is to understand the problem and just code it up.

We won't include any visualizations in this unit due to the intuitive nature of these problems.

However, sometimes, something can happen in these problems.

To see what we mean by that, we will look at a real USACO problem.

Link: Cannonball

Solution

Hmm. You might got TLE on some test cases. Let's look at why.

Sometimes, you might want to consider the possibility of infinite loops in simulation problems. Here, there is such possibility.

We sure can check for these infinite loops, but it is much easier to set a certain amount of iterations as a cap to hard stop the infinite loop. 

#include <bits/stdc++.h>
using namespace std;
 
int main() {
	int n, x;
	cin >> n >> x;
	vector<pair<int, int>> pad(n + 1);
	vector<bool> vis(n + 1);
	for (int i = 1; i <= n; ++i)
		cin >> pad[i].first >> pad[i].second;
	int dir = 1, power = 1, ans = 0;
	for (int reps = 0; reps < 5000000 && 1 <= x && x <= n; ++reps) {
		if (pad[x].first == 1 && power >= pad[x].second && !vis[x]) {
			vis[x] = true;
			++ans;
		}
		if (pad[x].first == 0) {
			dir *= -1;
			power += pad[x].second;
		}
		x += dir * power;
	}
	cout << ans << endl;
}
