Sets

Sets is a type of data structure where it can only store 1 unique item.

Vector can store multiple items of the same value. In a set, every item must be unique. 

set<int> s;

This line decalres a set for integers. 

s.insert(num);

This line inserts a number into s. If the number already exists, nothing will be added. If not, the number is added. 

s.insert(1);
s.insert(2);
s.insert(2);

In the end, only 1 and 2 will be in the set. The third line did nothing, since 2 is already in the set.

Solution

First, if we don't use sets, we can slightly tweak the solution we used in the pre-bronze section problem.

But now that we know sets, we can just append everything we received into the set and let the data structure does it job.

Pretty lazy, but it works. 

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    set<int> s;
    for (int i = 0; i<n; i++){
        int temp;
        cin >> temp;
        s.insert(temp);
    }
    cout << s.size() << endl;
}
