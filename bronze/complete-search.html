Complete Search

Sometimes you are asked to search for a solution. For Bronze, a complete search, meaning you iterate through every possibility, is often enough.

This is also known as brute force. Fortunately, this is ok for Bronze.

We won't include any visualizations in this unit due to the intuitive nature of these problems.

USACO Problem

As a reminder, brute force is enough.

Link: Milk Pails

Solution

Just iterate through all possible values of using X and Y. We will iterate through 1000 * 1000 = 10^6 times, which is enough. 

#include <bits/stdc++.h>
using namespace std;

int main() {
    freopen("pails.in", "r", stdin);
	freopen("pails.out", "w", stdout);

    int x, y, m;
    cin >> x >> y >> m;

    int ans = 0;
    for (int xPour = 0; xPour * x <= m; xPour++) {
        for (int yPour = 0; xPour * x + yPour * y <= m; yPour++) {
            int current = xPour * x + yPour * y;
            if (current > ans) {
                ans = current;
            }
        }
    }

    cout << ans << endl;
    return 0;
}
